## Overview

The apps directory is a container for application-level code and related submodules. At the root of this directory there are no standalone files; instead, application logic is organized into subdirectories. This directory's role is to group one or more application implementations so they are easy to find and manage within the repository.

Currently the directory contains a single subdirectory, cyoa-engine/, which itself contains one documented file. The apps directory therefore functions as an organizational boundary: it holds application implementations (each in its own subdirectory) rather than root-level scripts. Developers should look into each subdirectory to find the actual runnable components, documentation, and code for a given application.


### File Organization

There are no files at the apps root. Application code is placed in subdirectories (one per application or engine). This keeps the root clean and groups all files for an application together under its own folder, simplifying navigation and maintenance.
