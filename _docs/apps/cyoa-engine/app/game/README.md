## Overview

This directory holds the core client-side pieces required to render and run a simple choose-your-own-adventure game. At the root there are three TypeScript/TSX files: GameClient.tsx (a React-based game client component), page.tsx (a Next.js page that likely mounts or routes to the game UI), and story.ts (typed data structures and a concrete story instance named "Activation"). Together these files provide the UI component, the Next page entry for routing, and the typed story data that the UI consumes.

The files are organized to separate concerns: story.ts encapsulates the story model and a concrete story instance, GameClient.tsx contains the interactive React component that reads story data and presents choices, and page.tsx serves as the Next.js entry point that integrates the component into the app's routing. In the larger system this directory represents the game-specific frontend layer for the cyoa-engine app — supplying both the piece of UI and the story payload required to present the Activation narrative to users. Developers working here will typically modify story.ts to change content, GameClient.tsx to adjust presentation/interaction, and page.tsx to alter routing or server-side behavior for this page.


### File Organization

The directory uses a flat organization: one component file (GameClient.tsx), one route/page file (page.tsx), and one data/model file (story.ts). This keeps UI, routing, and story data separated for straightforward navigation and maintenance.
